# 사람 평가 안내 (파일럿 v4)

- 각 행은 기획안 하나입니다. 어떤 절차로 만들어졌는지는 가려져 있습니다. 성격 조건은 모두 같습니다(지정 없음).
- 평가자 A·B는 서로 상의하지 않고 각자 시트를 채웁니다. 1–5 정수.
  - S1 만족: 이 기획안을 내 작업에 참고하고 싶은 정도
  - S2 새 관점: 내가 떠올리지 못한 관점을 주는 정도
  - S3 후속 생각: 이 안을 보고 다른 아이디어가 떠오르는 정도
  - B/F/L(선택): 브랜드 적합 / 실행 가능성 / 논리
- 같은 브랜드의 비슷한 안이 여러 번 나올 수 있습니다. 순서는 무작위입니다.
- `_key_DO_NOT_OPEN_until_rating_done/`은 평가를 마친 뒤에만 엽니다.
