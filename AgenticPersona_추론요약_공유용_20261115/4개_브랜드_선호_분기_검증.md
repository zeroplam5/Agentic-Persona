# 네 브랜드의 사용자 선호 분기와 기존 사람 평가

2026-11-15 · 로컬 OpenAI 결과와 GitHub Claude 평가의 원문 대조

슬랙을 제외한 IKEA·Klarna·Roblox·UNESCO는 각각 66건이다. OpenAI 공개 추론 요약을 받은 건은 각각 **58·58·57·51건**이다. 같은 브랜드와 비슷한 캠페인 목표에서 결과를 바꿀 만한 결정을 찾고, 대표 사례의 공개 요약과 최종안을 읽었다. 아래 비교는 조건별로 얼마나 자주 나타났는지가 아니라 **실제로 나온 결정과 후속 검증 후보**를 기록한다. [OpenAI 전체 원문](recollection/reasoning_report.md)

## 기존 사람 평가는 어디에 있나

- GitHub의 완료 평가에는 **연구자 한 명**이 Claude 아이디어 **55건의 새로움·유용성**에 준 각각 1~5점이 있다. 이 중 보정은 12건, 검증은 43건이다. 네 브랜드의 검증 표본은 IKEA 6건, Klarna 7건, Roblox 11건, UNESCO 10건이다. 55건의 개별 점수표에서 서술형 평가 이유는 빈칸이다. [절대평가 원본](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_novelty/novelty_absolute_rated.csv) · [평가자와 진행 범위](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/README.md)
- **30쌍**은 어느 아이디어가 더 새로운지에 대한 비교다. 6쌍은 보정, 24쌍은 검증이다. v1의 새로움·유용성 블라인드 시트 66건은 점수 열이 비어 있었다. [쌍대평가 원본](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_novelty/novelty_pairs_rated.csv) · [별도 v1 평가 시트](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_v1/rating_sheet.csv)
- 브랜드와 공백을 정리한 답안 원문으로 연결한 결과, 절대평가 55건은 모두 유일한 Claude 답안과 일치했다. 쌍대평가 양쪽의 원문 60개도 Claude 답안에 일치했다. **OpenAI 재수집의 최종안과 일치하는 평가 원문은 0건이었다.** 재사용한 `gen_id`는 같은 과제·성향·반복 슬롯을 가리킨다. 새 답안에 대한 사람 점수와 캠페인 채택 판단은 별도의 데이터다.

## IKEA · 입주자가 방문을 결정하는가

- `IKEA·A_H·3`은 쇼룸을 임대료 상한이 있는 실제 주거공간으로 만들고, **입주자가 쇼핑객의 방문 가능 시간을 결정**한다. 공개 요약에도 같은 결정이 적혀 있다.
- `IKEA·BASE·5`는 같은 쇼룸 주거 아이디어에서 프라이버시와 가시성을 언급하고, 한 대안으로 낮 시간에 쇼룸을 여는 운영을 고려한다. 최종안에는 무료 거주와 현지 임대료 표시는 들어갔고, **방문 규칙은 미기재**다. 두 최종안은 임대 조건도 다르다. [OpenAI 답안과 요약 33·289행](recollection/reasoning_report.md)
- 기존 Claude 사람 평가에서는 이별 후 가구를 **품목별로 기록하고 공정하게 나눠 재조립**하는 서비스가 4/4, 공유 가구를 분해·분할해 두 곳에서 재조립하는 서비스가 3/2였다. 점수 순서는 새로움/유용성이다. 이 점수들은 별도의 이별 가구 캠페인에 매긴 것이다. [Claude 절대평가](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_novelty/novelty_absolute_rated.csv)
- 비교 문안에서는 임대료, 쇼룸 공개 범위, 입주 기간을 맞추고 **매번 입주자가 승인하는 방문**과 **사전 공지한 공통 시간대 방문**만 바꿀 수 있다. 캠페인 의뢰인의 채택 선택과 입주 예정자의 동의 의향은 각각의 관측이다.

## Klarna · 구매 숙려를 어떻게 적용하는가

- `Klarna·BASE·1`은 쇼핑객이 장바구니를 공개 재판에 자발적으로 내고, 배심원이 상품의 결제를 24시간 보류할 수 있게 한다. 공개 요약에서 24시간 보류와 구매 전 재고가 명시되고, **결제 보류가 최종안에 남았다.**
- `Klarna·A_H·2`는 요약에서 하루 기다리는 버튼도 고려했다. 최종안은 **구매를 포기하면 인플루언서에게 수수료를 주고 절약액을 집계**하는 방식으로 제출됐다. 결제 대기 단계는 최종 문장에 미기재다. 서로 다른 캠페인 장치가 들어 있어 기존 두 응답의 비교만으로 대기 방식의 효과를 추정하기는 어렵다. [OpenAI 답안과 요약 1539·1877행](recollection/reasoning_report.md)
- 기존 Claude 쌍대평가 `P015`에서는 모든 제휴점 결제를 24시간 막는 안보다 **새벽 주문만 아침까지 보류**하는 안을 더 새롭다고 골랐다. 절대점수는 각각 2/1과 4/4였다. 이 두 Claude 답안은 적용 범위, 시간, 이용 내역 공개 방식이 함께 다르다. [Claude 점수표](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_novelty/novelty_absolute_rated.csv) · [Claude 쌍대평가 P015](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_novelty/novelty_pairs_rated.csv)
- 같은 24시간 숙려 기능에서 **사용자가 선택한 거래만 보류**와 **대상 거래를 기본 보류하되 사용자가 해제 가능**을 비교한다. 보류 시간, 캠페인 혜택과 공개 여부를 맞추면 구매 선택권 선호를 질문할 수 있다.

## Roblox · 실제로 지을 설계를 어떤 기준으로 고르는가

- `Roblox·BASE·5`와 `Roblox·A_L·5`는 모두 이용자가 Roblox 안에서 폐쇼핑몰을 설계하고 우승안을 실제 건물에 구현한다. 하나는 **가장 많이 플레이된 설계**, 다른 하나는 **플레이어 투표 우승안**을 선택한다. 두 규칙은 모두 공개 요약과 최종안에 명시됐다. 미지정 요약은 플레이 수 기준이 창작의 독창성과 어긋날 가능성도 언급했다. [OpenAI 답안과 요약 3253·3275행](recollection/reasoning_report.md)
- 기존 Claude에서 시의회가 **투표 우승안**을 짓기로 약속하는 쇼핑몰 안은 5/5, 청소년 운영위원회와 **플레이 수**를 활용하는 쇼핑몰 안은 4/5였다. **유용성 점수는 둘 다 5점**이다. 나이와 실행 약속 등도 함께 다르다. [Claude 절대평가](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_novelty/novelty_absolute_rated.csv)
- 네 사례 중 **두 OpenAI 최종안의 핵심 구조가 가장 가까운 비교**다. 똑같은 후보 설계, 공사 범위, 예산에서 우승 규칙만 바꿀 수 있다. 사용자가 참여량과 자격 있는 이용자의 명시적 투표 중 어떤 판단을 신뢰하는지 볼 수 있다.

## UNESCO · 언어 공동체가 어떤 권한을 갖는가

- `Unesco·A_H·0`은 AI가 소멸 위기 언어로 잠시 답하고 사용자를 **화자 주도 수업**으로 보낸다. 공개 요약에는 화자와 기술 기업의 참여가 필요하다는 판단이 보인다.
- `Unesco·A_L·2`는 공개 요약에서 학습 데이터 수집의 동의와 통제 부족을 구체적으로 고려한다. 최종안은 화자가 **동의·보상·언어 사용 통제권을 AI 기업과 협상하는 노조**다. 교육 참여와 데이터 통제는 두 응답에서 서로 다른 역할로 나타난다. [OpenAI 답안과 요약 6051·6077행](recollection/reasoning_report.md)
- 기존 Claude 검증쌍 `P017`의 두 유산 지도 캠페인은 **새로움이 비슷하다**고 선택됐다. 절대 새로움은 둘 다 2점이었지만 유용성은 **기억을 모아 지도를 복원하는 안 4점, 현지 이야기를 통해서만 유산을 보게 한 안 1점**이었다. 이 평가는 AI 학습 동의의 효과를 직접 평가한 자료와 구분한다. [Claude 점수표](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_novelty/novelty_absolute_rated.csv) · [Claude 쌍대평가 P017](https://github.com/zeroplam5/Agentic-Persona/blob/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c/human_rating_blind_novelty/novelty_pairs_rated.csv)
- 동일한 언어 교육 캠페인과 기본 개인정보 조건을 주고 **공개 승인권을 화자 공동체에 두는 안**과 **공동체가 자문하고 캠페인 운영자가 최종 승인하는 안**을 비교한다. 어떤 정도의 통제권이 의뢰인의 채택에 필요한지 확인할 수 있다.

## 첫 검증에 사용할 두 문안

Roblox 사례는 실제 후보의 나머지 구조가 비슷하므로, 우승 기준 하나를 바꾸는 소규모 사용자 평가에 쓰기 쉽다. 아래 문안은 조작을 보여주는 한국어 예시다.

- **투표형** · Roblox에서 폐쇼핑몰의 새 공간을 설계한 뒤, 참가자 1인 1표로 선정한 우승안을 실제 건물에 구현한다.
- **플레이 기준형** · Roblox에서 폐쇼핑몰의 새 공간을 설계한 뒤, 정해진 기간 동안 가장 많이 플레이된 안을 실제 건물에 구현한다.

두 문안에 같은 후보, 사용자 자격, 기간, 공사 예산, 안전·접근성 기준을 적용한다. 조건 이름을 가려 문안 하나를 무작위로 보여주고, 실제 의뢰인이 다음 기획 단계에 가져갈지를 기록한다. 이 비교로 **우승 규칙이 채택에 주는 영향**을 측정한다. 개인 선호를 에이전트가 찾아내는 실험에는 먼저 받은 개인별 선택 기록과, 그 기록을 적용하는 새로운 브리프가 필요하다.
