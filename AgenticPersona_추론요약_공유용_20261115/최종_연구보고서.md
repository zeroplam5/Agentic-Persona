## 연구 질문

기존 파일럿은 같은 브리프에서 Big Five 성향 지시를 바꿨을 때 아이디어의 새로움·유용성·다양성이 달라지는지를 물었다. 후속 실험은 같은 과제를 한 번 요청해 **최종 아이디어와 같은 응답에서 반환된 공개 추론 요약**을 수집했다. 이를 읽어 어떤 대안이 언급되고, 어떤 결정이 최종안에 남으며, 사용자 채택을 검증할 비교 후보가 무엇인지 살폈다. [기존 연구 원문](https://github.com/zeroplam5/Agentic-Persona/tree/13396b8f4d3bc6bcffb69e3f6bfa1d02e822a35c)

## 설계와 수집 결과

- 원본과 동일한 시스템 프롬프트와 사용자 브리프를 사용했다. 5개 브랜드 × 11개 성향 조건 × 6회로 55개 조합, 총 330건이다. 조건은 성격 미지정과 Big Five 각 특성의 높음·낮음이다.
- GPT‑6.1 Terra의 OpenAI Responses API를 요청당 한 번 사용했다. `reasoning.effort=high`, `summary=auto`를 요청했고 실제 330개 응답 모두 요약 설정이 `detailed`로 반환됐다. [OpenAI 추론 요약 문서](https://developers.openai.com/api/docs/guides/reasoning#reasoning-summaries)
- 최종 답변 **330/330건**, 공백 기준 50단어 미만 **330/330건**이다. 추론 요약은 **273/330건(82.7%)**, 요약 길이는 중앙값 **245단어**, 범위 60~604단어였다. 요약이 빠진 57건에도 추론 토큰 사용량이 집계됐다.
- API가 보고한 사용량은 입력 84,852토큰, 출력 213,193토큰이며, 출력 중 추론은 200,005토큰이다. 기본 요금 환산 약 **US$1.1508**이다. [수집 코드](collect_openai.py) · [전체 집계와 원문](recollection/reasoning_report.md)

가령 Slack 친화성 높음의 한 요약은 직원 자발 참여를 언급했다. 최종안에는 참여 CEO와 팀 투표가 적혔고, 직원 개인의 동의 절차는 미기재였다. 이처럼 요약에 등장한 기준과 최종안에 구현된 내용을 함께 확인할 수 있다. 다섯 브랜드 표는 사례 분석이며 조건별 발생률을 추정한 표본 코딩은 아니다. [Slack 사례 판독](Slack_사용자_선호_분석.md) · [다른 네 브랜드의 원문과 비교 문안](4개_브랜드_선호_분기_검증.md)

## 기존 사람 평가와의 연결

GitHub 파일럿에는 연구자 한 명이 기존 Claude 답안 55건에 매긴 새로움·유용성 점수와, 새로움을 비교한 30쌍의 기록이 있다. 개별 평가는 보정 12건·검증 43건, 쌍대 평가는 보정 6쌍·검증 24쌍이다. 브랜드와 공백을 정리한 원문을 기준으로 55건과 30쌍을 연결했다. OpenAI 답안에 일치하는 평가 원문은 0건이다. 같은 `gen_id`는 모델 간 같은 브리프·조건·반복 슬롯을 가리킨다. [대조한 점수와 원본 출처](claude_human_ratings.json)

## 해석의 범위와 다음 검증

- **관찰 대상.** 공개 추론 요약에는 모델이 언급한 대안과 판단이 일부 드러난다. 요약 누락률은 성향별 6.7~33.3%로 다르다. 요약에서 특정 기준이 보이는 비율을 연구할 경우 성향별 분모와 미관찰 수를 함께 보고한다.
- **모델 비교.** 기존 Claude와 같은 프롬프트를 각 OpenAI 요청에 그대로 전달했다. 제공 모델과 추론 설정이 달라 기존 Claude 결과를 참고용으로 함께 보관한다.
- **사용자 선호.** 원래 프롬프트에는 개별 의뢰인의 선호가 들어있지 않았다. 여기서 확인한 것은 사용자에게 검증할 결정이다. 실제 채택과 개인 선호 추론을 검증할 때는 사용자가 앞서 한 선택과 새 과제의 채택 판단을 수집한다.
- **첫 채택 비교.** 같은 Roblox 쇼핑몰 캠페인에서 후보 설계·예산·기간과 최종 문안을 맞추고, 우승 기준만 플레이 수와 1인 1표로 바꾼다. 사용자가 실제 다음 기획에 채택하는지 기록한다. 같은 유형의 과거 선택을 모델에 주었을 때 새 과제에서도 이 기준을 적용하는지는 그 다음 비교다. [평가 문안 예시](4개_브랜드_선호_분기_검증.md#첫-검증에-사용할-두-문안)
