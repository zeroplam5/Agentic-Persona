# 파일럿 v3 분석 계획 (데이터 수집 전 고정)

고정 시점과 해시: `logs/freeze_hashes.txt`. 고정 뒤 바꾼 것은 이 파일 끝의 "변경 기록"에 적고 탐색적 분석으로 표시한다.

## 성격

모든 분석은 **탐색적**이다. 브랜드 3개, 조건당 12개 실행으로는 효과를 확정할 수 없다. p값은 쓰지 않고 효과 크기와 브랜드 단위 부트스트랩 95% 구간(브랜드 안에서 실행 재표집, 2,000회)을 보고한다. 비교가 여러 개이므로 구간이 0을 벗어난 결과도 우연일 수 있다.

## 주 비교 (미리 정함)

1. 개방성 효과: `X_O_H − X_AVG`, `X_O_L − X_AVG` (X = SB, LK 각각). 방향이 두 방식에서 같은지.
2. 보통 지정 vs 미지정: `SB_AVG − BASE`, `LK_AVG − BASE`.
3. 과정 vs 독립 표집: `BASE − NODEDUP`.

## 결과 변수

| 변수 | 수준 | 정의 |
|---|---|---|
| D_shapley (주) | 최종안 | 1/m, m = 브랜드 최종안 집합에서 같은 묶음에 든 실행 수 |
| D_rarity, unique, threshold | 최종안 | MuseScorer 정의 그대로(N = 브랜드당 실행 수) |
| 조건별 서로 다른 묶음 수 | 조건 × 브랜드 | 4개 최종안이 차지한 묶음 수(1–4) |
| 실행 내 구별도 | 실행 | 후보 집합에서 실행의 후보 4개가 차지한 묶음 수(1–4) |
| 선택 후보의 드묾 | 실행 | 선택된 후보의 후보 집합 내 shapley (구조화 조건만) |
| B, F, L | 최종안 | 1–5 원점수와 (x−1)/4, 재평가 쌍의 일치율과 가중 κ |
| P (주) | 최종안 | (B+F+L)/3 정규화. 보조: P_min = min, P_geo = 기하평균 |
| Auto | 최종안 | 100 × D_shapley × P (사람 점수 없음. 자동 선택용) |
| S | 사람 평가 48개 | ((S1+S2+S3)/3 − 1)/4, 두 평가자 평균. 항목별 원점수도 보고 |
| Composite (후보식) | 사람 평가 48개 | 100 × D_shapley × P × S. S 없는 행은 NA |
| Composite 보조 | 같음 | P_min 사용판, x/5 정규화판, 산술평균판 (D+P+S)/3 |
| 토큰 | 실행 | output_tokens 합, thinking 블록 수, 보이는 텍스트 길이 |
| 과정 기록 | 실행 | 수정 항목 수, 가정 수, 우려 수, 선택 후보 위치(C1–C4) |
| 조작 확인 | 조건 | Mini-Markers 5특성 평균(1–9), 관찰자 평정 5특성 평균 |

## 해석 규칙

- 조작 확인에서 목표 특성이 지시 방향으로 움직이지 않은 방식은 그 방식의 결과 차이를 "성격 효과"로 부르지 않는다.
- 다른 특성이 1점(9점 척도) 이상 같이 움직이면 "목표 특성만 바꾼 조작"이라고 쓰지 않는다.
- 조건별 토큰 사용량이 다르면 결과 차이와 함께 적는다. 토큰을 통제 변수로 넣은 분석은 하지 않는다(표본이 작다).
- 사람 점수는 평가자별로 따로 보고하고 두 평가자의 일치(스피어만, 가중 κ)를 먼저 본다.
- 사람 점수와 LLM 점수는 이름을 구분한다(`S_human`, `B_llm` 등). 사람 점수가 없는 행에 예측값을 채우지 않는다.
