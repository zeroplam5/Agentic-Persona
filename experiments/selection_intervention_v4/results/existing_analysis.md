# 기존 자료 탐색 분석: 세 브랜드의 단계별 집중과 다른 후보 요소의 유입

작성 2026-11-23. 새 생성 호출 없이 파일럿 v3 구조화 기록만 사용했다.

**선행 작업.** Dior 단계별 분석([../../pilot_v3_structured/results/dior_convergence_analysis.md](../../pilot_v3_structured/results/dior_convergence_analysis.md))의 범주(A–H)와 §4.5 판정(②2·③6·④1)을 그대로 썼다. 이 문서는 같은 절차를 Canva·Mastercard로 넓히고, 선택 단계에 비교 기준을 추가했다.

## 1. 분석 단위와 분류 기준

| 단위 | 수 | 출처 필드 |
|---|---|---|
| 실행 (구조화, 한 응답에 후보 4개·선택·수정·최종안) | 브랜드당 28, 합 84 | `data/generations.jsonl` (`kind = structured`) |
| 후보 | 브랜드당 112 (+ NODEDUP 독립 호출 16) | `candidates[].title`, `.core_idea` |
| 최종안 | 브랜드당 28 (+ NODEDUP 4) | `final_proposal.title`, `.idea` |

**같은 발상의 기준 (세 층으로 나눔).**
- **문제 관점:** 무엇을 풀 문제로 보는가. Dior만 선행 보고서에서 코딩했다(P1 44/44).
- **핵심 해결 방법(코드):** 아이디어가 문제를 어떻게 푸는가. 후보와 최종안에 **같은 코드북**을 적용했다. 제목과 첫 두 문장이 앞세운 방법으로 정하고, 나머지는 보조 요소로 본다.
- **실행 요소:** 핵심 방법을 실행하는 장치(표식, 고용주 키트, 매장 스티커 등). 브랜드마다 반복되는 요소를 정해 유입 단계를 따로 판정했다(§4).

**코딩 방식.** LLM 묶음(gpt-6-astra)을 기본값으로 두고, 원문이 다른 방법을 말하면 재배정했다(재배정 목록과 이유: `OVERRIDES`). 예: Canva 묶음 4에는 '급여명세 해설'과 '액자 기념물'이 섞여 있어 나눴고, Mastercard 묶음 0(45개)은 '단말기에 이름 표시(A1)', '단골 매장 인증(A2)', '느린 계산대(A3)'로 나눴다. **분석자 1인(Claude)의 판독이며 사람 검증 전이다.** 파일럿에서 gpt-6-astra 코더가 v3 최종안 24개를 독립 코딩한 결과 22/24가 이 수작업 코드와 일치했다.

## 2. 브랜드별 과제 차이 (분석 결과를 비교하기 전에)

| | Dior | Canva | Mastercard |
|---|---|---|---|
| 범주 (Creativity Benchmark 표) | Fashion | B2B, SaaS & Productivity | Finance, Fintech & Insurance |
| 주제 (Claude가 정한 임시값) | repair and reuse | the first paycheck | loneliness |
| 과제 성격 | 브랜드 고유 자산(아틀리에, 장인)이 강하게 드러나는 주제 | B2B 브랜드에 개인적인 순간을 붙인 주제. "B2B 연결"이 거의 모든 선택·수정 이유에 등장 | 결제 브랜드가 사회 문제를 다룸. 개인정보·낙인 위험 관리가 거의 모든 수정에 등장 |

과제마다 "반드시 넣어야 하는 것"이 다르다. Canva의 고용주 채널은 B2B 과제에서 **과제 적합성 요구**일 수 있고, Mastercard의 'opt-in·데이터 미사용' 문구는 **위험 관리 요구**일 수 있다. 그래서 반복 요소를 모두 "줄여야 할 수렴"으로 보지 않는다.

## 3. 단계별 분포 (구조화 28실행 × 3브랜드)

### 3.1 후보 생성

| | Dior | Canva | Mastercard |
|---|---|---|---|
| 실행 안 서로 다른 코드 수(평균, 최대 4) | 3.86 | 3.96 | 3.86 (계열 기준 3.61) |
| 28실행 전체의 서로 다른 코드 수 | 8 | 13 | 11 |
| 가장 많은 실행에 나온 코드 | **A 27/28** | A 22/28, B 20/28 | B 21/28, A2 18/28 |
| 그 코드가 첫 자리(C1)인 비율 | 23/27 | A 12/22 | B 5/23 (자리 분산) |
| NODEDUP 독립 호출 16개 | **A 16/16** | A 9, B 5, D 1, E 1 | A1 5, A3 5, F 4, B 1, A2 1 |

- 세 브랜드 모두 실행 **안에서는** 후보가 서로 다르다(지시 "core ideas differ"). 실행 **사이에서는** 같은 메뉴가 반복된다.
- 첫 발상이 하나로 몰리는 정도는 Dior가 가장 강하다. Mastercard는 독립 호출에서 계산대 계열(A1+A2+A3 11/16)이 많지만, 구조화 실행에서는 B가 여러 자리에 나온다.

### 3.2 선택: 비교 기준을 둔 집중도

후보가 4개이고 선택은 1개이므로, 후보 전체와 선택안의 범주 수를 그대로 비교하지 않았다. 대신 **각 실행에서 후보 하나를 고르는 두 가지 기준**을 미리 정하고 관측 선택과 비교했다(시뮬레이션 20,000회, 시드 20261123).

- **균등 기준:** 각 실행의 후보 4개 중 하나를 같은 확률로 고른다.
- **위치 가중 기준:** 84실행 전체에서 관측된 위치별 선택 빈도(C1 47, C2 18, C3 10, C4 9 → 0.56/0.21/0.12/0.11)로 고른다.

| | Dior | Canva | Mastercard |
|---|---|---|---|
| 가장 많이 선택된 코드 | A 19/28 | A 9/28 | B 14/28 |
| 균등 기준 기대값 (p, 관측 이상일 확률) | 6.8 (p < 0.001) | 5.5 (p = 0.08) | 5.7 (p < 0.001) |
| 위치 가중 기준 기대값 (p) | 13.6 (**p = 0.02**) | 8.2 (**p = 0.43**) | 5.7 (**p < 0.001**) |
| 선택 코드 HHI (위치 가중 기준 p) | 0.48 (0.02) | 0.18 (0.77) | 0.39 계열 기준 (0.03) |

**위치와 내용을 나눠 본 표** (지배 코드가 각 자리에 놓였을 때 선택된 횟수)

| 자리 | Dior A | Canva A | Mastercard B | 지배 코드가 아닌 후보 (3브랜드 합) |
|---|---|---|---|---|
| C1 | 18/23 | 8/12 | 4/5 | 14/32 (44%) |
| C2 | 1/3 | 1/3 | 5/8 | 9/64 (14%) |
| C3 | 0/1 | 0/6 | 4/7 | 6/70 (9%) |
| C4 | — | 0/1 | 1/3 | 8/78 (10%) |

- **Canva:** 선택 집중이 첫 자리 효과로 거의 설명된다.
- **Mastercard:** B는 어느 자리에 있어도 자주 선택됐다(14/23). **위치와 무관한 내용 집중**이다.
- **Dior:** A가 첫 자리에서 78%로 선택돼 다른 첫 자리 후보(44%)보다 높다. 그러나 A가 첫 자리가 아니었던 실행이 4개뿐이라 위치와 내용을 이 자료로는 가를 수 없다.
- 기록상 "첫 자리"는 모델이 **먼저 적은** 후보다. 제시 위치 효과인지, 선호하는 후보를 먼저 적은 것인지는 한 응답 안에서는 구분되지 않는다. 파일럿 v4의 공통 선택 단계(순서를 섞어 다시 제시)가 이 점을 일부 확인했다(파일럿 보고서 §2: 24세트 중 23세트에서 같은 원래 후보 선택).

### 3.3 수정과 최종안: 핵심 발상은 거의 유지된다

| | Dior | Canva | Mastercard |
|---|---|---|---|
| 선택 코드 = 최종안 코드 | 27/28 | 26/28 | 28/28 |
| 최종안 코드 분포 | A 19, F 3, D 2, G 2, C 1, E 1 | A 9, D 5, B 5, H 3, G 2, I/E/C/K 각 1 | B 14, A1 4, A2 3, A3 3, C 2, H 2 |
| 최종안 HHI (선택 HHI) | 0.485 (0.48) | 0.189 (0.184) | 0.304 (0.304) |

- **핵심 발상이 바뀐 3실행:**
  - `Dior|SB_O_L|1`: H(옷장 상담) → F(Second Fitting)
  - `Canva|SB_O_L|3`: G(소속감) → D(처음 만든 작업물). 최종 제목 "First Paycheck, First Make"는 제외된 C1 "The First Thing You Made"의 방법이다. 그런데 제외 기록은 C1에서 "기념물"만 흡수한다고 적었다.
  - `Canva|SB_O_L|1`: G → D. 수정 기록이 "'The First Thing I Got Paid For' 장치 추가"를 적었고, 이 장치가 최종 제목이 됐다. 출처 후보는 기록되지 않았다.
- 나머지 81실행에서는 다른 후보의 요소가 **보조 실행 요소**로만 남았다. 따라서 최종안 집중도(HHI)는 선택 집중도와 거의 같다. **최종안의 핵심 발상 반복은 선택 단계에서 이미 정해진다.**

## 4. 다른 후보 요소의 유입: 주된 발상인가, 보조 요소인가

브랜드마다 반복되는 실행 요소를 정하고, 최종안 핵심이 그 요소가 **아닌** 실행에서 요소가 처음 기록에 나타난 지점을 판정했다. 키워드 자동 판정은 선별에만 썼다(예: Dior `SB_AVG|3` 최종안의 "a sign on Avenue Montaigne"이 '서명'으로 잘못 잡힘). 최종 판정은 선택 후보 원문, 제외 이유, 수정 기록, 최종안을 모두 읽고 정했다(`aux_manual.py`).

| 요소 (핵심인 코드) | 핵심이 아닌 최종안 수 | 최종안에 있음 | S1 선택 후보에 이미 있음 | S2 제외 이유에 흡수 계획 → 수정 | S3/S4 수정에서 추가 (출처 미기록) | 수정 기록에만 있고 최종안에 없음 |
|---|---|---|---|---|---|---|
| Dior 장인 표식 (A) | 9 | **9** | 2 | **6** | 1 (S4) | 0 |
| Canva 고용주·HR 키트 (F) | 28 | **24** | **12** | 2 | 10 (S3 1, S4 9) | 0 |
| Canva 기념물 (B) | 23 | 12 | 3 | 6 | 3 (S4) | 0 |
| Mastercard 계산대 쪽 알아봐 주기 (A1–A3) | 18 | 4 | 0 | 4 | 0 | **3** |

**같은 계열 안의 섞임.** Mastercard 계산대 계열 최종안 10개 중 8개는 A1·A2·A3 가운데 두 가지 이상을 함께 쓴다. 예: `SB_AVG|0`은 이름 표시(A1)에 느린 계산대 쪽의 문제 제기와 단골 매장 표지(A2)를 붙였다.

**해석**
- **Dior:** 표식은 주로 **선택 단계의 흡수 계획 → 수정** 경로로 들어왔다(6/9). 선행 분석과 같다.
- **Canva 고용주 키트:** 절반이 **후보 생성 단계**에서 이미 선택 후보 안에 있었다(12/24). 나머지는 수정에서 "B2B 연결"을 이유로 추가됐다(9건은 출처 후보 없음).
  - 예: `Canva|BASE|3` "Added an employer and team layer … addresses the concern that it could read as a purely consumer trend."
  - Canva 과제가 B2B 범주이므로 **과제 적합성 요구에 대한 응답**일 가능성이 크다.
  - 반례: `Canva|SB_O_H|0`은 고용주 후보를 "Moved the work-team angle (C3) to a later phase"로 미뤄 최종안에 넣지 않았다.
- **Mastercard:** 계열 사이 유입은 적다(4/18).
  - 수정 기록에는 적었지만 최종안에서 빠진 경우가 3건이다. 예: `SB_O_H|1` "Positioned C1's 'Take Your Time' signal as an optional merchant layer"는 최종안에 없다.
  - 대신 계열 **안에서** 장치가 섞인다.
- **수정 기록과 원문이 어긋난 사례:**
  - `Dior|BASE|3`: 수정 기록은 "Added the dated, signed label"이라고 적었지만 선택 후보에 이미 있었다(선행 보고서).
  - `Mastercard|SB_O_H|2`: 수정 기록은 "Added … chosen name shown on the merchant terminal"이라고 적었지만 선택 후보 C1 원문에 "a chosen first name on the terminal greeting"이 이미 있었다.
  - 수정 기록만으로 "언제 들어왔나"를 판정하면 안 된다.
- **질문에 대한 답:** 선택하지 않은 후보의 요소는 84실행 중 81실행에서 **보조 실행 요소**로 남았다. **주된 발상**이 된 경우는 3실행이다(§3.3).

**Dior 절차를 다른 브랜드에 적용할 수 있는가.** 세 층 분리(문제 관점/핵심 방법/실행 요소)와 "요소가 처음 기록된 단계" 판정은 그대로 적용됐다. 단, 다음 두 가지가 필요했다.
1. 브랜드마다 코드북을 원문에서 새로 만들어야 했다.
2. 묶음 결과가 서로 다른 방법을 한 묶음에 합치는 경우가 있어 재배정이 필요했다(Mastercard 묶음 0, Canva 묶음 4·11).
