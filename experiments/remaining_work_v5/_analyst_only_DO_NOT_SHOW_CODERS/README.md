# 분석자 전용 (코더에게 보여 주지 말 것)

`link_llm_comparison.csv`에는 9건의 조건 이름과 LLM 코더 판정이 들어 있다. 두 연구자의 코딩과 조정이 끝나기 전에 코더에게 보여 주면 블라인드가 깨지고, 코더가 LLM 판정에 끌릴 수 있다.

## 기술적 비교 (9건, 일치도 통계로 쓰지 않음)

- 조건 분포: 세 조건 각 3건, 한 조건 0건. 사람 코딩 시트 순서가 무작위라서 생긴 결과이고, 의도한 표집은 아니다.
- Q1 일치: 6/9. 불일치 3건 중 2건은 Canva 급여명세 해설 최종안을 연구자 A가 C로 코딩한 경우이고, 1건은 Mastercard H 대 C다.
- Q2: 연구자 A는 partial 3건, LLM은 9건 모두 yes.
- Q3 후보 번호: 연구자 A가 적은 후보가 LLM의 다른 후보 요소 목록에 있는 경우 4/9.
  - LLM은 다른 후보 요소가 없다고 판정했는데 연구자 A는 후보를 적은 경우 3건.
  - 둘 다 후보를 적었지만 서로 다른 후보인 경우 2건.
- Q6 해당 브랜드 열 전부 일치: 5/9.

이 비교는 연구자 A의 답변과 가이드 v1.1 재검토 전 값을 기준으로 한 것이다. 형식 문제(§3) 때문에 요소 단위 일치는 계산하지 않았다.
