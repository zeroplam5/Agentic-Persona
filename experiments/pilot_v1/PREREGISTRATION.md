## 2. 변형 (우리가 추가한 부분 — 원 논문에 없음)

### 2.1 조건 (11개)

| ID | 성격 지시 |
|---|---|
| BASE | 없음 (원 시스템 프롬프트 그대로) |
| O_H / O_L | `You have High Openness to Experience.` / `You have Low Openness to Experience.` |
| C_H / C_L | `You have High Conscientiousness.` / `... Low Conscientiousness.` |

- 문구 출처: Kao & Volkova, *Evaluating LLM Alignment under Big Five Personality Prompting*, CEUR-WS Vol-4178 paper6 (CC BY 4.0), §3: `"You have [High/Low] [Extraversion/Agreeableness/Conscientiousness/Neuroticism/Openness to Experience]."` 원문 그대로이며 번역·수정하지 않았다.
- **위치(우리 선택):** 성격 문장을 원 시스템 프롬프트 **앞**에 두고 빈 줄 하나로 구분한다. 원 논문(CEUR)은 성격 문장 뒤에 설문 지시를 붙였으므로 "성격 문장 → 과제 지시" 순서를 따랐다.
- **나머지 4특성: 미지정**으로 둔다(CEUR 원 설계와 동일). 근거와 한계: Boone et al.(arXiv:2611.06572)은 미지정 특성이 함께 표류(spillover)한다고 보고했다. 따라서 5절의 조작 확인으로 표적 외 특성 변화를 측정한다. "보통(Average) 지정" 조건과 "성격 없이 일반 창의 지시" 조건은 이번 파일럿에서 **실행하지 않는다**(본 실험 후보로 남김).
- 원 시스템 프롬프트의 "bold / surprising / never cliché / provocative" 지시는 모든 조건에 동일하게 들어간다. 따라서 이 실험이 측정하는 것은 "강한 창의 지시 위에 성격 문장을 더했을 때의 차이"이다.

## 3. 평가 (우리가 정의 — 원 논문의 평가 방식이 아님)

원 논문은 인간 **쌍대 선호**와 Bradley-Terry를 썼다. 이번 파일럿은 개별 아이디어에 **절대 점수**를 매긴다.

### 3.1 LLM 평가자

- 아이디어마다 독립 호출 1회. 평가자에게는 브랜드명과 아이디어 문장만 보여 준다. **조건·모델·다른 아이디어는 보여 주지 않는다.** 평가 순서는 시드로 섞는다.
- 새로움(Novelty)과 유용성(Usefulness)을 각각 1~5점으로 매기고, 점수 앞에 짧은 근거를 쓰게 한다(채점표: `prompts/judge_prompt.txt`).
- **새로움의 참조 집합:** (a) 해당 브랜드와 범주에서 이미 실행되었거나 널리 알려진 캠페인, (b) 흔한 마케팅 스턴트 템플릿(팝업 스토어, 해시태그·인플루언서 챌린지, AR 필터, 한정판 드롭, 기부 연계 등). BASE 조건 응답은 참조 집합으로 쓰지 **않는다**(조건 간 비교가 오염되므로).
- **유용성:** 브랜드 적합성, 전략적 논리, 더 발전시킬 가치와 실현 가능성. 50단어 한 문장에 실행 계획까지 요구하지 않는다.
- 재검사 신뢰도: 무작위 20%(66개)를 다른 순서로 한 번 더 평가한다. 분석에는 1차 점수만 쓴다.
- 이 점수는 "평가 모델의 판단"이며 사람 평가나 연구자 개인 평가를 대신하지 않는다. 원 논문도 LLM 평가자가 인간 순위와 약하게만 일치한다고 보고했다.

### 3.2 종합점수 — 결과 확인 전 고정

- N = (새로움 − 1)/4, U = (유용성 − 1)/4 (0~1).
- **주 지표(공동 1차):** 새로움과 유용성 **각각의** 평균.
- **주 종합점수:** 산술평균 `100 × (N + U)/2`.
  - 선택 이유: 최종 공식이 아직 미정이고, 조화평균은 어느 한 항목이 1점이면 다른 항목과 상관없이 0이 된다. 그래서 파일럿 단계의 주 요약으로는 덜 엄격한 쪽을 쓰고, 엄격한 쪽은 민감도 분석으로 함께 본다. 본 실험의 공식은 사용자가 정한다.
- **보조 종합점수:** 조화평균 `100 × 2NU/(N + U)`, N + U = 0이면 0.
- **보조 지표:** 바닥 비율(새로움 = 1 또는 유용성 = 1인 아이디어 비율). 두 종합점수의 차이가 어디서 오는지 보여 준다.
- 모든 원점수(아이디어별 N, U, 근거)를 `data/judgments.jsonl`에 남긴다.

### 3.3 다양성 (집합 수준, 개별 점수와 분리)

- 브랜드×조건마다 6개 응답의 평균 쌍별 코사인 거리(원 논문의 Dm,p와 같은 정의, N = 6).
- 1차 임베딩: BAAI/bge-large-en-v1.5(원 논문과 동일). 이 환경에서 설치할 수 없으면 TF-IDF 코사인 거리로 대체하고 **이탈로 보고**한다. TF-IDF 거리는 어휘 다양성 보조 지표로 항상 함께 계산한다.

### 3.4 형식 준수

단어 수 50 미만 여부, 한 문장 여부(종결부호 개수 기준 휴리스틱), 머리말 유무.

## 4. 분석 계획

- 조건별로 새로움·유용성·두 종합점수·바닥 비율·다양성의 평균을 낸다.
- 각 성격 조건 − BASE 차이: 브랜드 안에서 조건 평균의 차이를 구하고, 이를 5개 브랜드에 걸쳐 평균한다. 95% 구간은 **브랜드 단위 부트스트랩**(10,000회)으로 구한다. 브랜드가 5개뿐이라 이 구간은 거칠다.
- 같은 특성의 High − Low 대비도 같은 방식으로 구한다.
- 효과 크기: 차이를 아이디어 단위 표준편차(전체 풀링)로 나눈 값. 일관성 지표로 "5개 브랜드 중 같은 방향인 브랜드 수"를 함께 보고한다.
- **다중 비교:** 10개 조건 × 여러 지표라서 우연히 큰 차이가 나올 수 있다. p값을 보고하지 않고 어떤 차이도 "확인됨"이라고 부르지 않는다. 모든 결과는 본 실험의 가설 후보이다.
- 해석 제한: 차이는 이 모델·이 프롬프트·이 평가자에서 관찰된 것이다. 사람 같은 성격이 있다거나 성격이 품질의 원인이라고 주장하지 않는다.

## 5. 조작 확인 (특성 표현과 교차 영향)

- IPIP 50-item Big-Five Factor Markers(Goldberg, 공개 도메인) 자기보고.
- 조건마다 3회 실행(총 33회). 시스템 프롬프트는 생성과 같고(성격 문장 + 원 시스템 프롬프트), 사용자 메시지로 설문을 준다. 원 시스템 프롬프트의 "한 문장" 규칙과 충돌하므로 사용자 메시지에 "이번 요청에서는 번호:점수 형식으로 답하라"를 명시한다(**우리 수정**).
- 50문항을 한 번에 제시한다(CEUR와 Boone et al.은 문항별·설문 단위로 다르게 실행. 우리 방식은 비용 절감용 변형).
- 보고: 조건별 5특성 점수(1~5)와 BASE 대비 표적 특성 변화, 표적 외 특성 변화(spillover).
- 한계: 자기보고 설문은 아이디어 문장에 성격이 실제로 드러나는지를 직접 측정하지 않는다.
