# 새로움 측정 개선 연구 — 분석 계획 (TEST 실행 전 작성·고정)

작성: 2026-11-12. 이 문서, 프롬프트, 표본 파일의 SHA-256 값은 TEST 평가를 요청하기 전에 `logs/freeze.json`에 기록한다. `novelty_study.py test`는 해시가 다르면 실행을 거부한다.

## 목적과 범위

- 파일럿 v1의 아이디어 330개를 다시 생성하지 않는다. 일부만 다시 평가한다.
- 비교할 새로움 측정 방식은 세 가지다.
  1. 기존 1~5점 절대평가
  2. 개선한 1~5점 절대평가
  3. 같은 브랜드 안에서 두 아이디어를 비교하는 쌍대 비교
- 목표는 분포를 고르게 펴는 것이 아니다. 판단 근거가 핵심 개념과 작동 방식에 맞는지, 재평가에서 일관적인지, 조건을 구분하는지를 확인한다.
- 평가자는 v1과 같은 `claude-opus-4-7`이며 Claude Code CLI로 호출한다. 그래야 방식 간 차이가 평가자 교체에서 오지 않는다.
- 평가자는 브랜드와 아이디어 문장만 본다. 성격 조건이나 기존 점수는 보지 않는다.
- **사람 평가는 아직 없다.** 따라서 어느 방식이 '더 타당한지'는 이번 결과만으로 결론 내리지 않는다.

- **TEST:** 동결한 뒤에만 평가한다. 결과를 보고 프롬프트나 지표를 바꾸지 않는다.
- **TEST 쌍대 비교 설계:**
  - 브랜드마다 조건 순서를 무작위로 정한다.
  - 11개 조건의 모든 조합 55쌍을 한 번씩 비교한다(라운드로빈). 브랜드 5개이므로 총 275쌍이다.
  - 각 조건은 브랜드마다 A 위치에 5번, B 위치에 5번 나온다(정규 토너먼트).
  - TEST 아이디어는 각각 5번 비교되며, A/B 위치는 3/2 또는 2/3으로 나뉜다.
- **순서 점검:**
  - 브랜드마다 14쌍(총 70)은 A/B를 뒤집어 다시 평가한다.
  - 브랜드마다 다른 14쌍(총 70)은 같은 순서로 다시 평가한다.
  - 둘을 비교하면 순수한 재평가 변동과 순서 효과를 나눠 볼 수 있다.

## 호출 순서

1. **1차 묶음**
   - 개선 루브릭 1차 110건
   - 기존 루브릭 재실행 110건(v1 점수와의 재평가 일치도 계산용)
   - 쌍대 비교 본평가 275건
2. **2차 묶음**
   - 개선 루브릭 2차 110건
   - 뒤집은 순서 70건, 같은 순서 반복 70건

호출 순서는 묶음마다 시드로 섞는다.

## 지표 (사전 명시)

1. **분포:** 점수별 빈도, 4–5점 비율, 평균, 표준편차, 엔트로피. 분포 모양만으로는 방식의 우열을 판단하지 않는다.
2. **재평가 일치도:**
   - 절대평가: 완전 일치, ±1 일치, 이차 가중 κ, Spearman, 평균 이동.
     - 기존 방식은 v1 점수 대 재실행 점수(같은 110개).
     - 개선 방식은 1차 대 2차.
   - 쌍대 비교: 같은 순서 반복과 뒤집은 순서 각각에서 같은 결론이 나온 비율, 승자가 바뀐 비율.
   - 순서 편향: 결론이 갈린 판정 가운데 A가 이긴 비율.
3. **조건 구분:**
   - 조건 평균은 브랜드에 같은 가중치를 둔다. 쌍대 비교는 아이디어별 승률(승 1, 비슷함 0.5)을 쓴다. 라운드로빈 균형 설계이므로 승률을 Bradley–Terry 대신 쓴다.
   - 신호 비율: 조건 평균의 분산 ÷ 브랜드 안에서 조건 라벨을 섞었을 때의 평균 분산(5,000회).
   - 순열 p값.
   - 칸 내 상관: 같은 칸의 TEST 아이디어 두 개 점수 사이의 상관(브랜드 평균 제거).
   - 조건 사이에 실제 새로움 차이가 없다면 구분이 낮은 것이 올바른 결과다. 따라서 구분도가 높다고 바로 '더 좋은 측정'으로 보지 않는다.
4. **방식 간 일치:**
   - 쌍대 비교에서 결론이 난 쌍 가운데, 절대 점수 차이의 방향이 승자와 맞는 비율.
   - 쌍대 비교가 '비슷함'인 쌍에서 절대 점수가 같은 비율.
   - 기존 점수와 개선 점수의 Spearman 상관.
   - 새로움과 v1 유용성의 상관(후광 효과 점검).
5. **근거 점검:**
   - "선례 없음"류 단정의 수를 정규식으로 센다.
   - "(uncertain)" 표시의 수를 센다.
   - `precedent_recall` 분포를 본다.

## 다음 단계 판단 규칙 (결과를 보기 전에 정함)

- **이번 TEST 결과로 할 수 있는 일:** 본 실험의 새로움 '측정 후보'를 좁히는 데까지만 쓴다. 주 지표 확정은 사람 평가 이후로 미룬다.
- **후보에서 제외하는 경우:**
  - 재평가 κ가 기존 방식보다 0.10 이상 낮은 방식
  - 쌍대 비교에서 뒤집은 순서의 결론 일치가 같은 순서 반복보다 15%p 이상 낮은 경우(순서 효과가 큼)
- **사람 평가 후 주 지표 선택:**
  - 사람 평가 test 세트에서 사람 판단과 가장 잘 맞는 방식을 주 지표로 정한다.
    - 절대평가는 사람 점수와의 Spearman으로 본다.
    - 쌍대 비교는 사람 쌍대 판단과의 일치율로 본다.
  - 차이가 사람 평가 표본의 부트스트랩 95% 구간 안이면 더 단순한 절대평가를 쓴다.
  - 사람 평가 calibration 세트는 평가 기준을 맞추는 데만 쓴다.
