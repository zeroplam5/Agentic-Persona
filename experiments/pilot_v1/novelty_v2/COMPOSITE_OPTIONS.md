# 새로움 측정이 바뀔 때 종합점수를 어떻게 할 것인가 — 후보와 검증 계획

현재 상태: **결정하지 않음.** v1의 대표 종합점수는 바꾸지 않았다. 공식은 `100 × (0.5·(N−1)/4 + 0.5·(U−1)/4)`이고, N은 기존 루브릭의 새로움, U는 유용성이다. `pilot_v1/results/`의 파일도 덮어쓰지 않았다. 새 측정은 `novelty_v2/results/`에 별도 열로만 저장한다.

## 문제

- **개선 절대평가(1~5):** 유용성과 같은 1~5 척도이다. 하지만 기준점이 옮겨졌다. 기존 4점이 대체로 새 3점에 해당한다. 그래서 새 점수를 그대로 넣으면 v1 종합점수와 숫자를 비교할 수 없다.
- **쌍대 비교 승률(0~1):** *같은 브랜드 안, 이번에 비교한 아이디어들 사이*의 상대적 위치이다.
  - 표본이 바뀌면 같은 아이디어도 승률이 바뀐다.
  - 시장 수준의 절대 새로움이 아니다.
  - 1~5 유용성과 단위·의미가 다르다. 따라서 근거 없이 50:50으로 더하지 않는다.

## 후보

| 후보 | 방법 | 장점 | 한계 |
|---|---|---|---|
| A. 분리 보고 (권장 기본값) | 새로움(어떤 방식이든)과 유용성을 각각 보고한다. 2차원 그림과 조건별 표를 쓴다 | 환산 가정이 없다. 맞교환(O_H/O_L)이 그대로 보인다 | 하나의 순위가 필요할 때 답이 없다 |
| B. 개선 절대평가로 v1 공식 재계산 | `100 × (0.5·(N₂−1)/4 + 0.5·(U−1)/4)`. N₂는 개선 루브릭 점수다 | 척도가 같아 계산이 단순하다 | 새로움 기준점이 이동해 v1과 수치 비교가 안 된다. 50:50이 실제 중요도와 같다는 근거가 없다 |
| C. 브랜드 내 백분위 결합 | 새로움 승률과 유용성을 각각 브랜드 안 백분위(또는 z)로 바꾼 뒤 평균한다 | 두 축의 단위를 맞춘다 | 상대 척도이다. 브랜드 간·실험 간 비교가 안 된다. 표본 구성에 의존한다 |
| D. 승률 → 1~5 보정 | 사람 절대 새로움 점수(또는 개선 절대평가)로 승률을 1~5로 환산하는 단조 함수(isotonic)를 calibration 세트에서 맞춘 뒤 v1 공식에 넣는다 | 쌍대 비교의 구분력과 절대 척도를 같이 쓴다 | 보정용 사람 평가가 필요하다. 표본이 작으면 환산 오차가 크다 |
| E. 유용성도 쌍대 비교 | 같은 쌍에서 유용성도 비교하고, 두 승률을 평균하거나 Bradley–Terry 2차원으로 추정한다 | 두 축이 같은 척도가 된다 | 호출 수가 두 배이다. 여전히 상대 척도이다 |

## 결과를 보고 유리한 쪽을 고르지 않기 위한 검증 계획

1. **사전 고정.** 본 실험(v2) 데이터를 생성하기 전에 다음을 사전등록에 적는다.
   - 주 새로움 측정. 이는 `ANALYSIS_PLAN.md`의 판단 규칙에 따라 사람 평가 test 세트에서 정한다.
   - 주 종합 방식
2. **사람 평가로 선택.** 사람이 같은 아이디어에 새로움(절대·쌍대)과 유용성을 매긴 뒤 정한다.
   - 사람 자료의 칸을 calibration과 test로 나눈다. 후보 D의 환산 함수는 calibration에서만 맞춘다.
   - 각 후보 종합점수가 사람의 종합 판단 순위를 얼마나 맞히는지 test 세트에서 비교한다.
     - 사람의 종합 판단은 "이 아이디어를 발전시키고 싶은가" 1~5와 같은 직접 문항으로 받는다.
     - 비교 지표는 Spearman과 쌍 일치율이다.
   - 차이가 부트스트랩 95% 구간 안이면 더 단순한 방식(A 또는 B)을 쓴다.
3. **본 실험 결과로는 바꾸지 않는다.** 본 실험의 조건 효과를 본 뒤에는 주 종합 방식을 바꾸지 않는다. 다른 후보는 보조 결과로 모두 보고한다.
4. **가중치.** 50:50은 연구 목적에서 정한 값이고 검증된 값이 아니다. 다른 가중치(예: 30:70, 70:30)에서 결론이 바뀌는지 민감도 분석으로만 보고한다.
