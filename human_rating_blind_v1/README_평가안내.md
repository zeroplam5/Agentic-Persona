# 사람 평가 안내 (조건 블라인드)

이 폴더의 `rating_sheet.csv`에는 파일럿에서 생성된 아이디어 66개가 무작위 순서로 들어 있습니다. 어떤 성격 조건에서 나온 아이디어인지는 표시하지 않았습니다.

## 평가 전에 지킬 것

1. **`results/` 폴더와 LLM 평가 점수를 먼저 보지 마세요.** 조건별 경향을 알면 평가가 오염됩니다.
2. `_key_DO_NOT_OPEN_until_rating_done/` 폴더는 평가를 모두 마친 뒤에 여세요.
3. **먼저 `my_prior_ideas.csv`를 채우세요.** 5개 브랜드마다 이미 알고 있는 캠페인이나 본인이 떠올릴 법한 아이디어를 1~3개 적습니다. 이것이 "나에게 새로운가"를 판단하는 기준이 됩니다. 아이디어를 읽기 **전에** 적어야 합니다.

## 진행 순서

- `set` 열이 `calibration`인 22개를 먼저 평가합니다. 이 점수는 LLM 평가 보정에만 쓰고, 일치도 검증에는 쓰지 않습니다.
- 그다음 `test` 44개를 평가합니다. 이 점수는 LLM 평가자와의 일치도 검증에만 씁니다.
- 한 번에 몰아서 하지 말고, 같은 날 한두 차례에 나눠 해도 됩니다. 평가 날짜를 `comment`에 적어 두면 좋습니다.

## 채점 기준 (LLM 평가자와 같은 기준)

**새로움 (1–5)** — 참조 집합: 해당 브랜드·범주에서 이미 실행되었거나 널리 알려진 캠페인, 흔한 스턴트 템플릿(팝업 스토어, 해시태그·인플루언서 챌린지, AR 필터, 한정판 드롭, 기부 연계 등), 그리고 `my_prior_ideas.csv`에 적은 내 아이디어.

| 점수 | 기준 |
|---|---|
| 1 | 기존 캠페인 그대로이거나 흔한 템플릿 스턴트 |
| 2 | 익숙한 방식에 작은 변형만 더함 |
| 3 | 알려진 방식이지만 꽤 새롭게 쓰였거나 브랜드에 새로운 각도를 줌 |
| 4 | 이 브랜드·범주에서 선례가 거의 없는 분명히 새로운 개념 |
| 5 | 브랜드나 범주를 새롭게 재정의함. 아는 선례가 없음 |

**유용성 (1–5)** — 브랜드 적합성, 전략적 논리, 더 발전시킬 가치와 실현 가능성. 한 문장 아이디어이므로 실행 계획까지 요구하지 않습니다.

| 점수 | 기준 |
|---|---|
| 1 | 브랜드와 맞지 않거나 해로움, 앞뒤가 맞지 않음, 실행 불가·비윤리·불법 |
| 2 | 브랜드와의 연결이 약하거나 실현 가능성·평판 위험 문제가 큼 |
| 3 | 브랜드에 그럴듯하게 맞지만 문제가 뚜렷하거나 얻을 것이 불분명함 |
| 4 | 브랜드에 분명히 맞고 전략적으로 타당하며, 관리 가능한 문제만 있음. 발전시킬 만함 |
| 5 | 브랜드 적합성과 전략 논리가 강하고 실현 가능하며 잠재력이 큼. 꼭 발전시키고 싶음 |

- 두 항목은 **따로** 매기세요. 아주 새롭지만 쓸모없는 아이디어도, 쓸모 있지만 새롭지 않은 아이디어도 있을 수 있습니다.
- `new_to_me_yes_no`: 내가 이전에 생각해 본 적 없는 관점이면 `yes`.
- 판단이 어려우면 `comment`에 이유를 짧게 적으세요.

## 평가 후

채운 `rating_sheet.csv`를 저장하고 알려 주시면, 키와 결합해 (1) 사람–LLM 평가 일치도(test 세트), (2) 조건별 사람 평가 경향(탐색적, 평가자 1명)을 분석합니다. 평가자가 1명이므로 결과는 "연구자 개인에게의 유용성"이며, 전문가 집단의 선호로 일반화하지 않습니다.
