# 사람 코딩 v1.1a (2026-11-26)

**지금 쓰는 파일**

| 파일 | 누가 |
|---|---|
| `CODING_GUIDE_v1_1.md` | 평가 기준. 코딩 전에 읽는다 |
| `ADDENDUM_v1_1a_sample6.md` | 표본 6건, 평가자, 결과 사용 방식. 가이드 §9–§10 대신 이 문서를 따른다 |
| `main_researcherA_6.xlsx` | 연구자 A (필수) |
| `main_researcherB_6.xlsx` | 연구자 B (선택). 하지 않으면 A의 평가만 쓴다 |

**쓰지 않는 파일:** `calibration_researcherB_9.xlsx`, `main_researcher*_24.xlsx`. v1.1 고정본으로 남겨만 둔다.

- 원본은 그대로 두고, 사본에 입력한다. 예: `main_researcherA_6_입력.xlsx`
- 시트는 보호되어 있다(암호 없음). 연노란 칸만 입력할 수 있다.
- 두 사람이 모두 평가하면, 서로 상의하지 않고 각자 입력한다.
- 이 폴더에는 실험 조건 정보가 없다.
- 해시: `FREEZE_v1_1.txt`
